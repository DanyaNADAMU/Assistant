# Assistant

Универсальный мультимодальный Telegram-бот и CLI для саммаризации, расшифровки речи (STT) и анализа любых медиаформатов.

## Возможности

- **Любые форматы на входе**: голос, музыка, подкасты, видео и «кружочки», документы (PDF/DOCX/TXT/Markdown), изображения и скриншоты (OCR), ссылки, текст и геолокация.
- **Отказоустойчивый роутер моделей**: у каждой категории есть пара Primary → Fallback с автоматическим переключением при `429`, `5xx` или таймаутах.
- **Pro-режим** (`/pro`) для углублённого разбора.
- Интерактивный inline-режим, пакетная обработка ссылок, экспорт документов, постоянный кэш ответов, персональные настройки и личный архив закладок.

## CLI

```bash
uv run assistant models                          # матрица моделей
uv run assistant process document.pdf            # саммари локального файла
uv run assistant process "https://example.com" --pro -o summary.md
uv run assistant tg-serve                        # запуск Telegram-бота
```

## CI/CD и деплой

GitHub Actions собирает и публикует образ в GHCR (`ghcr.io/danyanadamu/assistant`).
Ветки `feat/**`/`fix/**` деплоятся на тестовый стенд **Actions**; подписанные теги `v*`
деплоятся в **Ice** (продакшн).

## Безопасность

См. [`SECURITY.md`](SECURITY.md). Секреты хранятся в Ansible Vault (`Infra`) и
подставляются в рантайме через `.env`; в репозиторий ничего секретного не коммитится.
