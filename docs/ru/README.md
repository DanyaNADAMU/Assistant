# SummaryBot — Руководство пользователя и администратора

**SummaryBot** — всеядный мультимодальный Telegram-бот и CLI-утилита для саммаризации, расшифровки речи (STT) и анализа любых медиаформатов.

---

## 🎯 Возможности
* **Любые форматы на входе**:
  * 🎙️ Голосовые сообщения, музыка, подкасты, аудиофайлы (`.mp3`, `.ogg`, `.wav`, `.m4a`).
  * 📹 Видео и круглые видеосообщения Telegram («кружочки») (`.mp4`, `.mov`, `.webm`).
  * 📄 Документы и книги: PDF, DOCX, TXT, Markdown.
  * 🖼️ Изображения, скриншоты с текстом (OCR), мемы, стикеры, GIF-анимации.
  * 🔗 Ссылки на веб-страницы и статьи (автоматическое извлечение чистого текста через `trafilatura`).
  * 💬 Текстовые сообщения и микро-заметки.
  * 📍 Геолокационные точки.
* **Отказоустойчивый роутер (Primary ➔ Fallback)**:
  * В каждой категории запросов назначена пара моделей: основная и резервная.
  * При ошибках `429 Too Many Requests` (часто на бесплатных моделях), сбоях провайдера или таймаутах бот прозрачно переключается на Fallback-модель без прерывания работы.
* **Pro-режим**:
  * Поддержка флага `/pro` для углубленного экспертного разбора сложных документов и договоров.

## 💻 Использование через CLI

Утилита командной строки позволяет анализировать файлы и ссылки локально:

```bash
# Проверить матрицу настроенных моделей
uv run summary-bot models

# Обработать файл (аудио, видео, PDF, фото, текст)
uv run summary-bot process document.pdf

# Обработать ссылку в Pro-режиме с выводом в файл
uv run summary-bot process "https://example.com/article" --pro -o summary.md

# Запустить демон Telegram-бота
uv run summary-bot tg-serve
```

## 🚀 Развертывание на сервере (Test / Staging)

Бот развертывается как rootless Podman-контейнер под управлением systemd Quadlet:

1. **Пользователь**: `apps` на хосте `berg-test` (порт 4021).
2. **Сетевой шлюз**: выделенный контейнер `apps-proxy-gateway` (AmneziaWG) для гарантированного обхода внешних блокировок.
3. **Файлы стека**:
   * `/home/apps/stacks/SummaryBot/Containerfile`
   * `/home/apps/stacks/SummaryBot/SummaryBot.container`
   * `/home/apps/stacks/SummaryBot/.env` (права `0600`)

### Управление сервисом
```bash
systemctl --user daemon-reload
systemctl --user start SummaryBot
systemctl --user status SummaryBot
journalctl --user -u SummaryBot -f
```

## 🔐 Безопасность и регламент релиза
* **Гейт деплоя в прод**: развертывание в продакшн категорически запрещено без явной отправки пользователем строки `sdsd` в чат.
* **Секреты**: токены (`TELEGRAM_BOT_TOKEN`, `OPENROUTER_API_KEY`) хранятся в Ansible Vault репозитория `Infra` (SSoT) и зеркалируются в VaultWarden.
